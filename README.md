# CodeAlpha Language Translation Tool

## Project Overview

The Language Translation Tool is a Python-based web application that allows users to translate text between supported languages.

## Features

* Source language selection
* Target language selection
* Text input for translation
* Translation using an external API
* Display of translated text
* Input validation and error handling

## Technologies Used

* Python
* Streamlit
* Requests
* MyMemory Translation API

## Installation

1. Install Python 3.
2. Create and activate a virtual environment.
3. Install the required packages:

   `pip install -r requirements.txt`

## Run the Application

`streamlit run app.py`

## Usage

1. Select the source language.
2. Select the target language.
3. Enter the text.
4. Click Translate.
5. Read the translated result.

## Limitations

The application depends on an external translation service. Language availability, translation quality, and usage limits may vary.
